# Dry run: Green Thread Studio impact report

Continues the Green Thread Studio fixture (fictional 11-person apparel-repair
cooperative, Portland, calendar 2025). Drafts a source-traceable impact report
from the `materiality_output` produced by
`../../../materiality-interview/examples/green-thread-materiality/`,
demonstrating the proportionate small-org structure, per-claim source
traceability, and the open-items register — including refusing to turn a
repair count into an avoided-impact claim.

**Input given to the skill:** the materiality register handoff plus the same
fictional evidence pack (repair log, wage sheet, worker interviews, purchasing
log, supplier list, customer intake form).

See [impact-report.md](./impact-report.md) for the output.
