# Dry run: Green Thread Studio B Corp gap review

Runs the same fictional Green Thread Studio profile (11-person apparel-repair
cooperative, Portland, 2025 practices) against the B Impact Assessment's five
Impact Areas. This dry run demonstrates the indicative-review posture: no BIA
track or assessment export was supplied, so every finding is labeled
indicative and no official score is estimated. It stands alone but shares its
evidence pack with the materiality → report chain.

**Input given to the skill:** the fictional org profile and evidence pack
(repair log, wage sheet, worker interviews, purchasing log, supplier list,
customer intake form), with no BIA track/version or live assessment export.

See [gap-review.md](./gap-review.md) for the output.
