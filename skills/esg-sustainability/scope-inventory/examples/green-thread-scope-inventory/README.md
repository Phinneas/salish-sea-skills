# Dry run: Green Thread Studio scope inventory

Uses the same fictional Green Thread Studio org (11-person apparel-repair
cooperative, Portland, calendar 2025) as the rest of this category's dry
runs. This is the upstream "Session 3 inventory" the other fixtures reference
— the materiality dry run in
`../../../materiality-interview/examples/green-thread-materiality/` consumes
an inventory of this shape.

The fixture deliberately demonstrates the skill's three-state discipline:
Scope 2 is measured from bills, Categories 6–8 are estimated with disclosed
methods, and Categories 1 and 5 stay visible as **data gaps** (matching the
"waste baseline missing" and "no supplier screening" facts in the other
fixtures) rather than being collapsed into "screened out." The total is
labeled partial.

**Input given to the skill:** the fictional org profile, 2025 utility bills,
reimbursed-mileage log, a staff commute-pattern survey, and the note that
landlord-provided heat is included in the lease.

See [scope-inventory.md](./scope-inventory.md) for the output.
