# Dry run: Green Thread Studio materiality interview

First stage of the ESG reporting-layer dry-run chain. Green Thread Studio is a
fictional 11-person apparel-repair cooperative in Portland, Oregon, reporting
on calendar year 2025. The `materiality_output` handoff produced here (topics
MT-01…MT-05) is consumed verbatim by the report dry run in
`../../../impact-report-ghostwriter/examples/green-thread-impact-report/`.

**Input given to the skill:** the fictional org profile plus a small evidence
pack — repair log, wage sheet, two worker interviews, purchasing log, supplier
list, and a customer intake form. No Session 3 scope inventory was available,
so the fixture uses stable, documented placeholder source IDs to demonstrate
the expected inventory handoff shape rather than claiming to reproduce one.

See [materiality-register.md](./materiality-register.md) for the output.
