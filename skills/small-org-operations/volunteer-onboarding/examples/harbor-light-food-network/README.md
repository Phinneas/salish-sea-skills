# Dry run: Harbor Light Food Network volunteer onboarding

Uses the same fictional Harbor Light Food Network org. Designs onboarding for
the Saturday distribution greeter/stock assistant role — the role created by
the pilot decision in the board-packet dry run
(`../../../board-packet-generator/examples/harbor-light-food-network/`).
Demonstrates the role card, proportionate screening path, demonstration-based
training, first-shift brief, and 30-day follow-up plan.

**Input given to the skill:** the fictional mission, role tasks and
boundaries, schedule, supervisor, and policy inputs.

See [volunteer-onboarding.md](./volunteer-onboarding.md) for the output.
