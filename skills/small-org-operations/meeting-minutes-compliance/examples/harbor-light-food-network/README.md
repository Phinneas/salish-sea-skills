# Dry run: Harbor Light Food Network board minutes

Continues the Harbor Light Food Network fixture (fictional small nonprofit).
Converts raw notes from the 15 September 2026 hybrid board meeting — the
meeting prepared in
`../../../board-packet-generator/examples/harbor-light-food-network/` — into
draft minutes. The source notes deliberately omit attendance and quorum, so
the output demonstrates the `NOT RECORDED` / recorder-confirmation posture
rather than inventing governance facts.

**Input given to the skill:** fictional raw recorder notes, the agenda, and
the motion/vote fragments captured during the meeting.

See [board-minutes.md](./board-minutes.md) for the output.
