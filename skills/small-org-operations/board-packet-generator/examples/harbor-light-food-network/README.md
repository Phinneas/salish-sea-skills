# Dry run: Harbor Light Food Network board packet

Harbor Light Food Network is a fictional small nonprofit used across this
category's dry runs. This example builds the packet for the 15 September 2026
board meeting, where the primary decision is a proposed six-month Saturday
distribution pilot — demonstrating the cover memo, decision-brief format with
`DRAFT MOTION` labeling, financial/runway signal, and release check.

**Input given to the skill:** the fictional meeting frame plus source
documents — July approved minutes, August finance dashboard, a pantry
expansion memo, and the action register.

See [board-packet.md](./board-packet.md) for the output. The same meeting is
then recorded in
`../../../meeting-minutes-compliance/examples/harbor-light-food-network/`.
