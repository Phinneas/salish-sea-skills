# Dry run: Cascade Watershed Alliance × EPA Environmental Education

Continues the same illustrative Cascade Watershed Alliance example. The
fit assessment flagged missing partnership letters as a 5-point gap; this
dry run drafts the actual kit, covering all three letter types against
four different partners so the type-sorting logic (Process step 1) has
real cases to run against, not just one.

**Input given to the skill:** the four partner relationships named across
the logic model and budget narrative — a school district providing
general endorsement, two subaward recipients each committing a named
staff member's time, and an unfunded volunteer partner providing expert
guidance — plus what each is actually contributing, pulled from the
budget narrative's Contractual section and the logic model's Resources/
Inputs column.

See [letters.md](./letters.md) for the output.
