# Dry run: Cascade Watershed Alliance × EPA Environmental Education

Continues the same illustrative example, now past the application stage —
Cascade Watershed Alliance has won the award. This dry run builds the
reporting calendar for the resulting award and drafts the first
performance and financial report, using the same outputs/outcomes from
`logic-model-builder`'s dry run and the same budget categories from
`budget-narrative-writer`'s dry run, so the report traces directly back to
what the application claimed.

**Input given to the skill:** the award's period of performance (August 1,
2020 – July 31, 2021, per the NOFO's stated earliest start date and a
1-year project period), a stated semiannual reporting frequency
(illustrative — the source NOFO excerpt didn't specify a frequency, so
this dry run states that assumption plainly rather than treating it as
fact), and six months of real-ish period data (through January 31, 2021)
for the actual report.

See [report.md](./report.md) for the output.
