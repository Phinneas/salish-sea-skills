# Dry run: Cascade Watershed Alliance × EPA Environmental Education

Continues the same illustrative Cascade Watershed Alliance example used
across this trio's dry runs. This one takes the logic model built in
`../logic-model-builder/examples/cascade-watershed-alliance-epa-ee/` and
builds the budget narrative it should fund — including the NOFO's two
mandatory 25% mechanics (non-federal cost-share match and the
EPA-funds-to-subaward requirement), which the fit assessment flagged as a
real capacity risk worth watching closely rather than assuming away.

**Input given to the skill:** rough per-category cost estimates the org
provided (staff time, known equipment/supplies costs, the subaward
structure required by the NOFO), the logic model's activities, and the
fact that the org has no negotiated indirect cost rate agreement (NICRA)
and will elect the de minimis rate.

See [budget-narrative.md](./budget-narrative.md) for the output.
